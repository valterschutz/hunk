Filter the review stream by hunk state: the View menu shows or hides undecided, accepted, rejected, and fixed hunks each on its own, `shown_hunks` sets the starting set, `V` switches between every state and undecided only, a bindable command shows every state or hides them all, and the status line shows the filter as one rail-colored dot per state, filled while shown.
